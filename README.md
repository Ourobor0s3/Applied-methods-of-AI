# Applied-methods-of-AI

**Тема:** «Прогноз криптовалют с учётом новостей»

## 1. Введение и теоретическая база

### 1.1. Актуальность темы
Криптовалютный рынок известен своей высокой волатильностью и чувствительностью к информации. В отличие от традиционных финансовых рынков, где фундаментальные показатели компании играют ключевую роль, цена криптоактивов в значительной степени зависит от рыночных настроений (market sentiment), новостного фона, регуляторных заявлений и активности в социальных сетях. Поэтому разработка модели, способной учитывать не только исторические данные о цене, но и качественную информацию из новостей, является критически важной для повышения точности прогнозов.

### 1.2. Цель проекта
Разработать и обучить модель машинного обучения для прогнозирования краткосрочного движения цены криптовалы Bitcoin на основе комбинации исторических рыночных данных и количественных характеристик, извлеченных из новостных статей.

### 1.3. Ключевая терминология

**Рыночная капитализация (Market Capitalization):** Общая стоимость всех добытых (находящихся в обращении) монет криптовалюты. Рассчитывается как `Цена монеты * Текущее количество монет в обращении`.
**Волатильность (Volatility):** Статистический показатель, характеризующий тенденцию рынка к изменению цены. Высокая волатильность означает, что цена актива может резко измениться за короткий промежуток времени.
**Объём торгов (Trading Volume):** Общее количество монет, которое было продано и куплено за определённый период времени (обычно за 24 часа). Высокий объём часто подтверждает силу ценового тренда.
**Ликвидность (Liquidity):** Способность актива быть быстро проданным по цене, близкой к рыночной. Высокий объём торгов обычно коррелирует с высокой ликвидностью.
**Сентимент-анализ (Sentiment Analysis):** Метод обработки естественного языка (NLP), используемый для определения эмоциональной окраски текста (позитивная, негативная, нейтральная). В контексте криптовалют это позволяет оценить "бычий" (bullish) или "медвежий" (bearish) настрой рынка.
**Токенизация (Tokenization):** Процесс разбиения текста на отдельные элементы (слова, символы), которые называются токенами. Это первый шаг в подготовке текстовых данных для модели машинного обучения.
**Признак (Feature):** Измеримая характеристика или свойство объекта, используемое для обучения модели. В нашем проекте признаками будут как числовые данные из CoinMarketCap (например, цена, объём), так и производные от новостей (например, средний сентимент за последний час).
**Целевая переменная (Target Variable):** То, что мы пытаемся предсказать. В нашем случае это может быть будущая цена или, что чаще, направление движения цены (вырастет/упадет) и его величина в процентах (`percent_change_1h` или `percent_change_24h`).
**Временной ряд (Time Series):** Последовательность данных, упорядоченная по времени. Цены криптовалют и поток новостей являются классическими примерами временных рядов.
**Лаг (Lag):** Сдвиг временного ряда во времени. Использование лаговых значений (например, цена 1 час назад, цена 2 часа назад) позволяет модели учитывать историческую динамику.

## 2. Используемые данные и источники

Для достижения цели проекта мы используем два основных источника данных, описанных ниже.

### 2.1. CryptoPanic (Новостной фон и рыночные настроения)

> **CryptoPanic** — это агрегатор новостей и аналитики для криптовалютного рынка. Платформа собирает публикации из сотен источников (новостные сайты, блоги, Twitter, Reddit), предоставляет фильтрацию по тональности (bullish/bearish), важности и популярности, а также предлагает API для разработчиков. Сервис полезен для мониторинга рыночных настроений, построения торговых сигналов и анализа влияния новостей на цену активов.

**Что используем:**
*   **Текст новостей (`title`, `description`):** Для анализа тональности и выявления ключевых событий.
*   **Временные метки (`published_at`):** Для синхронизации новостей с движением цены.
*   **Пользовательские оценки (`votes`):** Прямой количественный показатель рыночных настроений (количество позитивных, негативных реакций, отметок "важно"). Это мощный признак, так как он отражает реакцию сообщества, а не просто факт публикации.
*   **Инструменты (`instruments`):** Для фильтрации новостей, относящихся к интересующим нас криптовалютам (BTC, ETH).
*   **Рейтинг новости (`panic_score`):** Проприетарная метрика важности, которую можно использовать как вес для новости.

### 2.2. CoinMarketCap (Рыночные данные)

**Назначение:** Источник структурированных, количественных данных о состоянии рынка.

**Что используем:**
*   **Целевая переменная:** Значения `price` или `percent_change_1h` из `quote`.
*   **Признаки:**
    *   Текущие и исторические значения цены.
    *   Объём торгов и его изменения (`volume_24h`, `volume_change_24h`).
    *   Процентные изменения за разные периоды (`percent_change_1h`, `percent_change_24h`, `percent_change_7d`). Они сами по себе могут служить хорошими признаками для прогнозирования следующего часа.
    *   Доля рынка (`market_cap_dominance`).

## 3. План реализации и методология

Проект будет реализован в несколько этапов.

### 3.1. Этап 1: Сбор и агрегация данных (Data Ingestion & Aggregation)
*   **Разработка скриптов:** Написание Python-скриптов для регулярного опроса обоих API.
*   **Параметризация:**
    *   CryptoPanic: Запрос новостей по интересующим валютам (например, `currencies=BTC,ETH`). На бесплатном тарифе мы ограничены, поэтому `filter=important` может помочь получать только значимые новости.
    *   CoinMarketCap: Периодический (например, раз в час) запрос актуальных котировок (`quotes/latest`) для выбранных валют по их ID.
*   **Создание "сырого" хранилища:** Сохранение полученных JSON-ответов в сыром виде в базе данных (например, PostgreSQL) или в облачном хранилище (например, AWS S3) для возможности переобработки в будущем.

### 3.2. Этап 2: Обработка данных и инжиниринг признаков (Data Processing & Feature Engineering)
*   **Обработка рыночных данных:**
    *   Очистка и приведение к единому временному ряду с часовым шагом.
    *   Создание лаговых признаков: `price_lag_1h`, `price_lag_2h`, `volume_lag_1h` и т.д.
    *   Создание скользящих средних (MA) и других технических индикаторов на основе цен и объёмов.
*   **Обработка новостных данных:**
    *   **Агрегация по времени:** Группировка новостей по часовым интервалам, соответствующим шагу рыночных данных.
    *   **Количественные признаки:** Для каждого часа рассчитываем:
        *   Общее количество новостей.
        *   Средний `panic_score`.
        *   Суммарное количество `positive`, `negative`, `important` голосов.
        *   "Чистый сентимент" (Net Sentiment) = (`positive` - `negative`) / (`positive` + `negative` + 1).
    *   **Качественные признаки (NLP):**
        *   Проведение сентимент-анализа заголовков и описаний новостей за каждый час (например, с помощью предобученной модели, такой как `FinBERT`).
        *   Использование тематического моделирования (LDA) для определения основных тем обсуждаемых в новостях (например, "регулирование", "взлом", "партнерство").
*   **Объединение данных:** Финальный датасет формируется путем объединения рыночных и новостных признаков по временной метке (часу).

### 3.3. Этап 3: Построение и обучение моделей (Modeling)
*   **Постановка задачи:** Мы можем решать задачу как регрессию (предсказание конкретной цены или процента изменения) или как классификацию (предсказание направления движения: цена упадет (0), останется примерно такой же (1), вырастет (2)).
*   **Базовые модели (Baseline):**
    *   Линейная регрессия или логистическая регрессия для оценки линейных зависимостей.
    *   Случайный лес (Random Forest) и Градиентный бустинг (XGBoost, LightGBM) как мощные модели для структурированных данных.
*   **Продвинутые модели:**
    *   **LSTM (Long Short-Term Memory):** Тип рекуррентной нейронной сети (RNN), специально разработанный для работы с временными рядами и способный "запоминать" долгосрочные зависимости. Это основной кандидат для нашей задачи.
    *   **Трансформеры (Transformers):** Современные архитектуры (например, Temporal Fusion Transformer), которые показывают отличные результаты в задачах прогнозирования временных рядов и могут эффективно обрабатывать как числовые, так и категориальные (например, темы новостей) признаки.

## API CoinMarketCap (Pro)

> **CoinMarketCap** — ведущая платформа аналитики криптовалютного рынка. Предоставляет данные о ценах, объёмах, рыночной капитализации, рейтингах и метриках для тысяч криптоактивов. Pro API позволяет получать актуальные котировки, исторические данные, метрики ликвидности и интеграционные вебхуки. Сервис широко используется для построения торговых ботов, дашбордов, аналитических отчётов и ML-моделей прогнозирования.

---

### Endpoint: Latest Quotes

**Метод:** `GET`  
**URL:** `https://pro-api.coinmarketcap.com/v2/cryptocurrency/quotes/latest`

⚠️ **Аутентификация:** во всех запросах необходимо указывать заголовок `X-CMC_PRO_API_KEY` с вашим API-ключом.

**Пример запроса:**
```bash
GET /v2/cryptocurrency/quotes/latest?id=1&aux=cmc_rank&convert=EUR
Headers:
  X-CMC_PRO_API_KEY: your_api_key_here
  или можно как параметр
```

### 3.4. Оценка и валидация (Evaluation)

### Интеграция с темой проекта

Для задачи **«Прогноз криптовалют с учётом новостей»** данные CoinMarketCap могут использоваться как:
- **Целевые переменные**: `price`, `percent_change_24h`, `volume_24h` для прогнозирования.
- **Признаки**: `market_cap_dominance`, `volume_change_24h`, исторические `%_change` для обучения моделей.
- **Валидация**: сопоставление новостей из CryptoPanic с фактическими движениями цены из CoinMarketCap.

## 4. Ожидаемые результаты и выводы

В результате выполнения проекта мы планируем:
1.  Разработать джоб сбора и обработки данных из двух различных API.
2.  Создать датасеты, объединяющий рыночные и новостные признаки.
3.  Постораться построить и сравнить прототип модели машинного обучения. 
4.  Количественно оценить вклад новостных признаков в качество прогноза по сравнению с моделями, использующими только цену и объём. Мы ожидаем, что учет новостного фона позволит статистически значимо улучшить точность прогнозов, особенно в моменты высокой волатильности.
5.  Сделать выводы о том, какие именно аспекты новостей (тональность, важность, объем, тематика) являются наиболее значимыми предикторами движения цены.

> 🔗 **Связка API**:  
> `CryptoPanic (новости)` → `Feature Engineering` → `CoinMarketCap (цена)` → `ML-модель` → `Прогноз`
