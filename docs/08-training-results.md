### Анализ

**XGBoost** уверенно лидирует с R²=0.5942 — модель объясняет ~59% дисперсии волатильности.
Это хороший результат для финансового временного ряда.

- Слишком маленький датасет (~3000–5000 точек после агрегации по дням)
- Финансовые данные имеют низкое соотношение сигнал/шум
- TimeSeriesSplit оставляет мало данных для валидации
- Отсутствие batch normalization + мало эпох для маленького датасета

1. Направление цены BTC на 15-минутном интервале не поддаётся прогнозированию
  с текущим набором признаков
2. Новостной сентимент (bull/bear голоса) не улучшает предсказание направления
3. Для улучшения нужны: более длинный горизонт прогноза, дополнительные признаки
  (он-чейн метрики, макро-индикаторы), или переход к вероятностному прогнозу

## Эксперимент: фильтрация и взвешенная агрегация новостей (15.05.2026)

**Дата запуска:** 15.05.2026
**Изменение:** переход от простой агрегации новостей к weighted aggregation с quality_score.
Новостных признаков стало 17 вместо 11.

### Что было изменено

1. **Hard filtering** (жёсткая фильтрация): удалялись новости с низким quality_score,
  малым числом голосов, спам-заголовками. Результат: отсеялось ~50% новостей, R² не изменился.
2. **Weighted aggregation** (взвешенная агрегация): ВСЕ новости остаются, но каждая
  получает вес `quality_score` при дневной агрегации. Формула:
   где:
  - `reaction_intensity = |positive_votes × 1.0 + important_votes × 0.5 − negative_votes × 0.8|`
  - `consensus_score = |positive − negative| / (total_votes + 1e-8)`
  - `total_votes = positive + negative + important`

### Выводы

`FORECAST_HORIZON = 3` (45 мин) оптимален для обеих задач.
Увеличение горизонта монотонно ухудшает волатильность; для направления
цены небольшой пик на horizon=20 не compensates общего ухудшения.
Горизонт 100 часов непригоден для прогнозирования текущими методами.

## Рекомендации

### Что работает

- **XGBoost** для волатильности — надёжный выбор, R²=0.600
- **NLP-эмбеддинги** — единственный эксперимент с воспроизводимым приростом (+0.6% R², +0.3% ROC)
- **PCA 256** — даёт дополнительный прирост XGBoost (+0.17% R²) относительно PCA 64
- Объём торгов и волатильность — главные предикторы будущей волатильности

### Что не работает (пока)

- Прогноз направления цены — все модели ≈ случайный выбор
- Нейросетевые модели на малом датасете — отрицательный R²
- Фильтрация/взвешивание новостей — без значимого эффекта на данном датасете
- Увеличение эмбеддинг-модели (0.6b → 8b) без увеличения PCA — прироста нет

### Пути улучшения

1. **Волатильность:** использовать короткий горизонт (3 свечи, 45 мин) —
   увеличение до 20 и 100 монотонно ухудшает R² (0.600 → 0.183 → 0.135);
   добавить он-чейн метрики (объём, Open Interest)
2. **Классификация:** горизонт 20 даёт небольшой прирост (0.535 → 0.540),
   но при 100 моделям падает ниже random — оптимальный горизонт 3–20;
   перейти к многоклассовой (рост/flat/падение), добавить макро-признаки
3. **Данные:** увеличить период (5+ лет), добавить другие криптовалюты — ключевое
   ограничение, размер датасета (~3000 точек) узкое место всех экспериментов
4. **NLP:** эмбеддинги через Ollama работают, но PCA 256 — потолок на текущем
   датасете; добавить эмбеддинги как признаки для нейросетей (сейчас только XGBoost
   их эффективно использует); попробовать агрегацию эмбеддингов без PCA (raw 4096 → mean)
5. **XGBoost tuning:** подбор гиперпараметров (max_depth, learning_rate, n_estimators)
6. **Нейросети:** увеличить датасет, добавить dropout/batch norm
