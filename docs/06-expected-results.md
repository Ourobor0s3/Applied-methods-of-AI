# 4. Ожидаемые результаты и выводы

В результате выполнения проекта мы планируем:

1. Разработать джоб сбора и обработки данных из двух API
2. Создать датасет, объединяющий рыночные и новостные признаки
3. Построить и сравнить прототип модели машинного обучения
4. Количественно оценить вклад новостных признаков в качество прогноза
5. Определить наиболее значимые предикторы движения цены

> 🔗 **Связка API**:  
> `CryptoPanic (новости)` → `Feature Engineering` → `CoinMarketCap (цена)` → `ML-модель` → `Прогноз`
