# Applied-methods-of-AI: Прогноз криптовалют с учётом новостей

## О проекте

Проект разрабатывает модель машинного обучения для прогнозирования краткосрочной волатильности Bitcoin на основе комбинации исторических рыночных данных и новостного фона.

## Как это работает (текущее состояние)

1. **Сбор данных**: Скрипты опрашивают два API:
   - **CryptoPanic** — новости, голоса пользователей, panic_score
   - **CoinMarketCap** — цена BTC, объём торгов, рыночные метрики

2. **Обработка**: Данные агрегируются по часовым интервалам и объединяются в единый датасет

3. **Моделирование**: На основе экспериментального анализа (Phase 1) выявлено:
   - Объём торгов — доминирующий предиктор волатильности
   - Новостная активность предсказывает волатильность, но **не** направление цены
   - Голоса пользователей реактивны и не обладают прогностической силой

4. **Текущий фокус**: Прогноз **диапазона волатильности** вместо направления цены; тематическая кластеризация новостей вместо сентимент-анализа
