# 2. Используемые данные и источники

Для достижения цели проекта мы используем два основных источника данных.

## 2.1. CryptoPanic (Новостной фон и рыночные настроения)

**CryptoPanic** — агрегатор новостей и аналитики для криптовалютного рынка. Платформа собирает публикации из сотен источников (новостные сайты, блоги, Twitter, Reddit), предоставляет фильтрацию по тональности и важности, а также API для разработчиков.

**Что используем:**
- **Текст новостей** (`title`, `description`) — для анализа тематики и выявления ключевых событий
- **Временные метки** (`published_at`) — для синхронизации с движением цены
- **Пользовательские оценки** (`votes`) — количественный показатель реакции сообщества
- **Инструменты** (`instruments`) — фильтрация по криптовалютам (BTC, ETH)
- **Рейтинг новости** (`panic_score`) — метрика важности от 0 до 100

## 2.2. CoinMarketCap (Рыночные данные)

**Назначение:** Источник структурированных количественных данных о состоянии рынка.

**Что используем:**
- **Целевая переменная:** `price`, `percent_change_1h`
- **Признаки:**
  - Текущие и исторические значения цены
  - Объём торгов и его изменения (`volume_24h`, `volume_change_24h`)
  - Процентные изменения за разные периоды
  - Доля рынка (`market_cap_dominance`)
