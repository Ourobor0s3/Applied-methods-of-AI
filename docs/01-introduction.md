# 1. Введение и теоретическая база

## 1.1. Актуальность темы

Криптовалютный рынок известен своей высокой волатильностью и чувствительностью к информации. В отличие от традиционных финансовых рынков, где фундаментальные показатели компании играют ключевую роль, цена криптоактивов в значительной степени зависит от рыночных настроений (market sentiment), новостного фона, регуляторных заявлений и активности в социальных сетях. Поэтому разработка модели, способной учитывать не только исторические данные о цене, но и качественную информацию из новостей, является критически важной для повышения точности прогнозов.

## 1.2. Цель проекта

Разработать и обучить модель машинного обучения для прогнозирования краткосрочного движения цены криптовалюты Bitcoin на основе комбинации исторических рыночных данных и количественных характеристик, извлеченных из новостных статей.

## 1.3. Ключевая терминология

| Термин | Определение |
|--------|-------------|
| **Рыночная капитализация** | Общая стоимость всех добытых монет криптовалюты: `Цена × Количество монет в обращении` |
| **Волатильность** | Статистический показатель, характеризующий тенденцию рынка к изменению цены |
| **Объём торгов** | Общее количество монет, проданных и купленных за период (обычно 24 часа) |
| **Ликвидность** | Способность актива быть быстро проданным по цене, близкой к рыночной |
| **Сентимент-анализ** | Метод NLP для определения эмоциональной окраски текста (позитив/негатив/нейтрально) |
| **Токенизация** | Разбиение текста на отдельные элементы (токены) |
| **Признак (Feature)** | Измеримая характеристика объекта, используемая для обучения модели |
| **Целевая переменная** | То, что модель пытается предсказать |
| **Временной ряд** | Последовательность данных, упорядоченная по времени |
| **Лаг (Lag)** | Сдвиг временного ряда во времени |
